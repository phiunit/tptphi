# Format Playbook — what sells on TPT beyond lesson plans

Research snapshot (Sep 2026). Ranked by (a) middle school demand, (b) fit for our
print-first pipeline, (c) fit for the four lines. Sources in docs/STRATEGY.md context:
TPT seller blog, gold-city/accio market surveys, teacher-author blogs.

## Tier 1 — build these next (high demand, perfect pipeline fit)
| Format | Why it sells | Our angle |
|---|---|---|
| **Task cards** | Massive evergreen demand; teachers use for stations, review, early finishers. Print, cut, reuse — the "flashcard" of TPT. Market is crowded, wins on NICHE topics — ours are wide open. | Concept decks per line: "Prompt Power-Ups" (AI vocab + challenge cards), "Money Moves" (finance scenarios), "Playtest Cards" (game design critiques). 24–32 cards + recording sheet + answer key. |
| **Escape rooms / breakout challenges** | Top engagement format; premium prices ($8–15); works print-only (envelopes + clue stations). | Our analogies ARE puzzle narratives: "Escape the Literal Genie," "Beat the Budget Boss." Decode-the-prompt ciphers, spot-the-hallucination clues. |
| **Bell ringers / warm-ups packs** | Volume sellers — "a month/year of daily openers." Secondary teachers buy these on repeat. | "Future Skills Daily": 4 weeks × 5 prompts per line (would-you-rather risk dilemmas, spot-the-slop AI answers, one-line copywriting fixes). Slide-sized pages + student sheet. |
| **Doodle / sketch notes one-pagers** | Proven retention pitch (dual-coding), teens love them, teachers buy for engagement + display. | Our inline-SVG art system is built for this — frame-and-icon note pages: "The P.R.O. Framework doodle notes," "10 Mental Models sketch pages." |
| **Unit bundles** | The biggest earners for secondary sellers; teachers want ecosystems, not one-offs. | Already in catalog (wave 3). Every new format feeds the line bundle — design components to bundle from day one. |

## Tier 2 — strong, build once Tier 1 exists
| Format | Notes |
|---|---|
| **Sub plans / emergency kits** | Desperation purchases = price-insensitive. Our no-prep + unplugged DNA is exactly a sub plan. "Future Skills Sub Kit: any teacher, zero tech, 50 minutes." |
| **Review mystery games ("Whodunnit")** | Gamified review is a proven top-seller pattern in secondary math; maps to our games line ("Who Broke the Game Economy?"). |
| **Posters / classroom decor sets** | Mental models line is BORN for this: "10 Mental Models" poster set (8.5×11 + big formats). Decor sells year-round, peaks in back-to-school. |
| **Choice boards / menus** | Cheap to make from existing activities; differentiation keyword sells. |
| **Exit ticket packs** | We already ship exit tickets inside lessons — repackage standalone 40-ticket packs. |

## Tier 3 — digital / interactive
- **BUILT (Sep 2026) — platform-agnostic companions in every zip:** a fillable PDF worksheet
  (typeable in any viewer) and a projectable .pptx deck per lesson (opens in PowerPoint, Keynote,
  Google Slides). See docs/PIPELINE.md "Digital companion". Listings should say both.
- **Self-checking digital (Boom Cards, Google Slides add-ons, Easel):** big and still growing; teachers
  split evenly between Boom and Slides. Boom needs per-platform authoring — skipped on purpose.
  TPT's Easel can auto-layer digital onto our PDFs at upload — enable it on each listing.
- **Interactive notebooks:** foldables/glue-ins; strong in middle school but high production fiddliness.

## Format rules (extend ANTI_SLOP)
1. Task cards: 4 per US-Letter page, cut lines printed, card backs optional, ALWAYS include
   recording sheet + answer key. Number every card.
2. Escape rooms: include a teacher setup page with a station map and a no-print-budget variant.
3. Bell ringers: one prompt per projectable page + a 5-per-page student strip version.
4. Doodle notes: fill-in blanks carry the content; art frames it. Blank-line version included
   for photocopier-friendly differentiation.
5. Every format still gets: standards chips, timing, no-prep statement, unplugged variant.
