Lead Your AI Squad

A 45-minute capstone. The hook: an AI agent is a party member — capable, tireless, extremely literal. Party leaders don't redo the squad's work; they write the quest card, assign the roles, and check the loot. Stands alone; no earlier lesson required.

Objectives

  • Students can write a complete quest card (goal · what we know · rules of the run · done looks like) that a literal-minded agent could follow without guessing.
  • Students can split a project into squad roles (planner, scout, critic) and execute a role from the quest card alone.
  • Students can review work against the CHECK rubric (accuracy, taste, done-ness) and write a specific run-it-back note.

Warm-Up — It Did EXACTLY What You Said (7 min)

Tell the class about your new party member: maxed-out stats, never sleeps, never complains — and painfully literal. Three orders from last night's run:

"Guard the door." → Guarded the door. Only the door. The enemies came in through the window.

"Grab everything in the chest." → Everything. Including the cursed amulet with the obvious skull on it.

"Wait here." → Still waiting. It has been three in-game days.

Then ask: whose fault was that — the party member's, or the orders? (Lesson 1 alumni will call it: this party member IS the literal genie — it just joined your squad. New classes need no backstory.)

Bridge: "An AI agent is this party member: fast, tireless, never salty — and it does exactly what the quest says. You'll never out-grind it. You CAN out-lead it. Today you learn the leader's loop: quest card, roles, check the loot — then ship it or run it back."

Direct Instruction — The Party Leader's Loop (10 min)

Write the loop on the board: QUEST CARD → ROLES → CHECK THE LOOT → SHIP IT or RUN IT BACK.

QUEST CARD. Four parts, in writing: goal (what winning means), what we know (who it's for, what the team already has), rules of the run (limits — length, tone, deadline), done looks like (the exact thing handed back). Prompt-writers: this is P.R.O. grown up.

ROLES. Leaders don't send one member to solo the raid. Split it: a planner, a scout, a critic — same card, one slice each.

CHECK THE LOOT. The leader checks accuracy (facts verified?), taste (fits the audience and vibe?), done-ness (everything the card asked for?).

SHIP IT or RUN IT BACK. Good work ships. Weak work gets a run-it-back note — keep + fix, specific enough that nobody guesses.

Model one quest card live on the board:

Cursed orderParty leader's quest card
"Plan the game night.""GOAL: get 6th graders to actually show up to Game Night. WHAT WE KNOW: Friday, gym, 6–8 pm; we have board games and two TVs. RULES OF THE RUN: school-appropriate, big readable title, 40 words max. DONE LOOKS LIKE: one flyer draft, ready to photocopy."
Say it plainly: "Party leaders don't do the quest twice. If you have to redo a party member's work, your quest card failed. Fix the card, not just the work."

Activity — Run the Quest (22 min)

  1. Write the quest card (6 min): Teams of 3 pick a quest on the worksheet — Game Night page or zine issue #1 — and write ONE card with all four parts.
  2. Squad works (8 min): Each teammate takes a role card — planner, scout, critic — and works ONLY from the quest card, silently, on their own paper. No questions: agents can't read minds. (In Sana's squad: DeShawn plans, Lucia scouts, Sana critiques.)
  3. Leader review (8 min): Rotate — Sana reviews DeShawn, DeShawn reviews Lucia, Lucia reviews Sana. Each leader runs the CHECK rubric (worksheet p.2), rules SHIP IT or RUN IT BACK, and writes one run-it-back note.

Exit Ticket (6 min)

Worksheet p.2: one complete quest card for a real task in their own life — all four parts labeled — something they'd actually hand an AI agent this week.

Differentiation

  • Support: Quest card sentence starters (Teacher Guide, p.2).
  • Extension: Write a card so tight the critic can't land a note — or invent a fourth squad role.
  • ELL: The four card labels double as language frames; draft in the strongest language first, then translate.
  • No-device classrooms: Built in — the teammates ARE the agents.
  • With devices: Run the team's card through a real AI tool and review ITS output with the same rubric.
